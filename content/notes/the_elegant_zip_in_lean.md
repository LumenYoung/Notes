最近在用 lean 学 functional programming 。

不得不说，当我写出下面的 zip 的时候，实在是太舒服了。

这种「爽」的感觉，主要来自于在写的过程中，我每一个觉得不够优雅的担忧，都在随后的过程中意识到可以非常轻松，以及非常简单的解决。

这种强力的 pattern matching 的能力，让我虽然没有办法写连续的几个操作(像在写 python 一样)也能够轻松的表达这些复杂的操作。
