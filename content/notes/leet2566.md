## Thought

Swap all occurrences of a digit into another. How to know if it is the largest or smallest? 

largest: find the first digit from higher digit that is not 9.
smallest: replace the first digit with 0.

## Takeaway

the way we break down digits should be not finding the highest first, rather to find the lowest digit first. 
```cpp
  vector<int> decomposeNumToDigits(int num) {
    int curr_num = num;
    vector<int> digits{};
    while (curr_num != 0) {  // Changed condition
      digits.push_back(curr_num % 10);  // Get last digit
      curr_num = curr_num / 10;
    }
    reverse(digits.begin(), digits.end());  // Reverse to get correct order
    return digits;
  }
```

Also when compose value from digit, we can instead of using power use 10 to time current value.
```cpp
  int composeDigits(vector<int> digits) {
    int value{0};
    for (size_t i = 0; i < digits.size(); i++) {
      value = value * 10 + digits[i];  // More efficient than pow()
    }
    return value;
  }
```
